Keyboard shortcuts

Alt+H / Alt+L
Focus tree / details
j / k or ↑ / ↓
Navigate the focused pane. In editors j/k type text; arrows choose suggestions.
h / l or ← / →
Collapse / expand a tree branch or focused section
Enter
Open the selected item, activate a control or apply filters
Escape
Close filters or the inspector and return
/
Show all filters and focus Text
Tab / Shift+Tab
Next / previous filter field; otherwise follow controls
Ctrl/Cmd+R
Clear filters while editing them
[ / ]
Previous / next detail section
Page Up / Down
Scroll the focused pane; Home / End go to its start / end
n / Shift+N
Next / previous matching policy
p
Pin / unpin the selected policy
Ctrl/Cmd+C
Copy selected text, or the policy ID outside inputs
Ctrl/Cmd+O
Open a policy export
Ctrl/Cmd +/-/0
Zoom; Ctrl/Cmd+wheel also zooms
